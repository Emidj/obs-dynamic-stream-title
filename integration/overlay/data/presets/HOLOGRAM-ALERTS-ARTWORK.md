# Futuristic Hologram · Animated Alerts · 0.12.27

Original procedural geometry authored in the shared alert shader and icon
generator. Open cyan/violet depth rings, travelling scans, projected beams,
translucent diamonds and narrow projection base; no scene background and no
expanding solid rectangle. Portrait remains circular and centred.

Six independent icon clips: pulse heart, crown with sequential gems, hinged gift,
staggered gift pack, celebrating group and rotating wire crystal. Transparent
facets, depth outlines, moving scan and orbiting light fragments. Components are
drawn independently during offline generation, not moved as a single PNG.

48 frames, 128×128, 24 fps, two seconds; sheets 1024×768 RGBA. APNG/GIF review
copies. OBS samples only the active cached sheet; no per-frame decoding/uploads.
All effects share the existing renderer, timeline, caches and Twitch service.

1000×1000 transparent canvas. Independent entry/hold/exit; continuous reversed
entry for exit. Real event profile image is awaited before starting the timeline.
Font inheritance, automatic centred name plate, ping-pong and private TEST remain.
